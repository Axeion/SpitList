Spitfire paint colours were identified by a factory code as well as a name, and
the same name can cover more than one formulation across the production run. The
registry stores both the colour name and the code where an owner supplies them.

**There is no chart on this page yet, on purpose.** A paint chart is only useful
if it is right, and a wrong code sends someone to a paint mixer with money in hand.
The figures circulating on forums disagree with one another often enough that
publishing a merged version would be inventing authority we do not have.

## What to use instead

For an individual car, the original colour is recorded on its
[Heritage Certificate](/reference/heritage-certificates), taken from the factory
ledger. That is the answer for *your* car, which is usually the question being
asked.

## Helping fix this

If you have a chart from a club publication, a factory document, or a paint
supplier's cross-reference, that is exactly what this page needs. The provenance
matters as much as the numbers — a chart we cannot attribute cannot be published
here either.
